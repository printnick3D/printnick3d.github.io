# Калькулятор стоимости 3D-печати

Веб-приложение для расчета стоимости 3D-печати, адаптированное для GitHub Pages.

## Особенности

- Полностью клиентское приложение (работает в браузере)
- Не требует серверной части
- Сохранение истории расчетов в localStorage
- Поддержка различных материалов (PLA, PETG, ABS, ASA, Nylon, TPU)
- Учет дополнительных услуг (моделирование, постобработка, упаковка)
- Адаптивный дизайн

## Как использовать

1. Выберите материал из списка
2. Укажите вес детали в граммах
3. Укажите время печати в часах
4. Выберите коэффициент сложности
5. Выберите принтер или укажите мощность своего
6. Задайте параметры дополнительных услуг (при необходимости)
7. Нажмите "Рассчитать стоимость"

## Локальная разработка

Просто откройте файл `index.html` в браузере или используйте Live Server в VS Code.

## Развертывание на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите файлы:
   - `index.html`
   - `calculator.js`
3. В настройках репозитория включите GitHub Pages
4. Выберите ветку и папку (обычно `root` или `/docs`)

## Функции

- Автоматический расчет при изменении параметров
- Сохранение расчетов с именами
- История последних 20 расчетов
- Экспорт/импорт данных
- Сброс к начальным значениям

## Технологии

- HTML5
- CSS3 (Tailwind CSS)
- Vanilla JavaScript
- Font Awesome иконки
- LocalStorage для хранения данных
